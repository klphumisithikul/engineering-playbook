# Templates

Copyable starting points for new artifacts. Unlike [`code-starter/`](../code-starter) (actual config files meant to be copied verbatim into a new repo), these are **fill-in-the-blank documents** — copy the file, replace the bracketed placeholders, delete this note.

| Template | Use when |
|---|---|
| [readme-template.md](./readme-template.md) | Starting a new project/repo and need a README |
| [architecture-template.md](./architecture-template.md) | Documenting a system/service's architecture |
| [onboarding-template.md](./onboarding-template.md) | Writing a new-hire or new-contributor onboarding guide |
| [api-design-template.md](./api-design-template.md) | Designing a new API (REST/RPC/GraphQL) before building it |
| [testing-template.md](./testing-template.md) | Writing a test plan for a feature or release |
| [ci-cd-template.md](./ci-cd-template.md) | Pointer to the runnable CI/CD starters elsewhere in this repo |
| [project-setup-template.md](./project-setup-template.md) | Standard folder structure for a new codebase |

For process/governance docs (not fill-in-the-blank), see [governance/](../governance) and [standards/](../standards) instead.
