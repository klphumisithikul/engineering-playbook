# Setting Up a GitHub Repository to Industry Standards

A concrete, step-by-step checklist for standing up a *new* GitHub repository correctly from day-one - not after a security incident forces the issue. Built from the GitHub's own official guidance (CC BY 4.0) plus the California Department of Technology's published GithHub standards, which aggregates the same GitHub docs for government engineering teams.

**Sources** 
* [GitHub Docs: Best practices for repositories](https://docs.github.com/en/repositories/creating-and-managing-repositories/best-practices-for-repositories) (CC BY 4.0) 
* [GitHub Docs: About rulesets] (https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/about-rulesets) (CC BY 4.0)
